# 13 · 专有词速查表 — 初学者友好版

> 这不是完整 AWS 百科,而是 SAA 题目里最常见的词义对照。遇到缩写先来这里找"白话意思",再回对应章节看选型。

## 一、考试问法常见词

| 术语 | 白话解释 | 看到它时先想 |
|------|----------|--------------|
| **MOST / LEAST** | 最符合 / 最少 | 题目在比较优先级,不是问能不能做 |
| **minimal operational overhead** | 运维负担最少 | 托管服务、serverless、自动化 |
| **cost-effective** | 满足需求下性价比最高 | 先满足硬要求,再省钱 |
| **highly available** | 高可用 | 多 AZ、自动故障转移 |
| **fault tolerant** | 能容忍部分组件失败 | 冗余、解耦、重试 |
| **resilient** | 有韧性,故障后能恢复 | 多 AZ、备份、DR、自动恢复 |
| **scalable** | 能随流量扩展 | Auto Scaling、serverless、托管服务 |
| **durable** | 数据不容易丢 | S3、备份、复制 |
| **compliant** | 满足法规/公司规定 | 加密、审计、不可篡改、报告 |
| **least privilege** | 最小权限 | IAM policy 只给必要动作 |

## 二、基础设施词

| 术语 | 白话解释 | 典型服务 |
|------|----------|----------|
| **Region** | AWS 地理区域 | Tokyo、Virginia、Singapore |
| **AZ** | Region 内独立机房组 | 多 AZ 部署 |
| **VPC** | 私有云网络 | 子网、路由、安全组 |
| **Subnet** | VPC 内的一段网段 | Public / Private subnet |
| **ENI** | 网卡 | EC2、Lambda in VPC |
| **Security Group** | 实例级防火墙 | stateful |
| **NACL** | 子网级防火墙 | stateless |
| **Route Table** | 路由表 | 决定下一跳 |
| **Internet Gateway** | VPC 进出公网的门 | Public subnet |
| **NAT Gateway** | 私有子网主动访问公网 | 单向出网 |
| **VPC Endpoint** | 私网访问 AWS 服务 | Gateway / Interface |

## 三、架构与可靠性词

| 术语 | 白话解释 | 常见答案方向 |
|------|----------|--------------|
| **Single point of failure** | 单点故障 | 多 AZ、冗余、托管服务 |
| **Failover** | 主故障后切到备 | RDS Multi-AZ、Route 53 |
| **RTO** | 最多能停多久 | 影响 DR 方案速度 |
| **RPO** | 最多能丢多久数据 | 影响备份/复制频率 |
| **DR** | 灾难恢复 | Backup、Pilot Light、Warm Standby、Active-Active |
| **Active-Active** | 两边都在服务 | 最贵,恢复最快 |
| **Pilot Light** | 备区只保留核心 | 比备份快,比双活便宜 |
| **Warm Standby** | 备区小规模运行 | 恢复快但有持续成本 |
| **Backup and Restore** | 备份后恢复 | 最便宜,恢复最慢 |

## 四、数据与存储词

| 术语 | 白话解释 | 常见服务 |
|------|----------|----------|
| **Object** | 整个文件对象 | S3 |
| **Block** | 像硬盘块设备 | EBS |
| **File system** | 有目录结构的共享文件 | EFS / FSx |
| **Lifecycle policy** | 按时间自动转冷/删除 | S3、日志 |
| **Versioning** | 同一个对象保留多个版本 | S3 防误删 |
| **WORM** | 写一次读多次,不能改 | S3 Object Lock |
| **Encryption at rest** | 静态数据加密 | KMS、SSE |
| **Encryption in transit** | 传输加密 | TLS、HTTPS、VPN |
| **IOPS** | 每秒读写次数 | 数据库、小块随机 I/O |
| **Throughput** | 每秒传输数据量 | 大文件、日志、视频 |

## 五、数据库词

| 术语 | 白话解释 | 常见服务 |
|------|----------|----------|
| **OLTP** | 在线交易,小而频繁的读写 | RDS、Aurora、DynamoDB |
| **OLAP** | 分析查询,扫大量数据 | Redshift、Athena |
| **Read Replica** | 只读副本 | 读扩展 |
| **Multi-AZ** | 跨 AZ 高可用 | 自动故障转移 |
| **ACID** | 事务可靠性的四个特性 | RDS/Aurora 典型 |
| **Eventually consistent** | 最终一致 | DynamoDB/S3 常见概念 |
| **Strongly consistent** | 强一致 | 读到最新写入,可能更贵/更慢 |
| **Cache** | 内存缓存 | ElastiCache、DAX |
| **CDC** | 捕获数据变化 | DMS、DynamoDB Streams、Kinesis |

## 六、消息与事件词

| 术语 | 白话解释 | 常见服务 |
|------|----------|----------|
| **Queue** | 队列,任务排队处理 | SQS |
| **Topic** | 主题,广播给订阅者 | SNS |
| **Event bus** | 事件总线,按规则转发 | EventBridge |
| **Stream** | 连续数据流 | Kinesis、MSK |
| **Fan-out** | 一条消息分发给多个下游 | SNS -> SQS |
| **DLQ** | 死信队列,放失败消息 | SQS / Lambda |
| **Visibility Timeout** | 消息被取走后暂时不可见 | SQS |
| **At-least-once** | 至少投递一次,可能重复 | SQS Standard、Lambda 异步 |
| **Idempotent** | 重复执行也结果正确 | 处理重复消息必备 |
| **Replay** | 重新播放历史事件 | Kinesis、EventBridge |

## 七、安全词

| 术语 | 白话解释 | 常见服务 |
|------|----------|----------|
| **Principal** | 谁发起请求 | User、Role、Service |
| **Policy** | 权限规则 | IAM、S3 Bucket Policy |
| **Role** | 可被临时扮演的身份 | EC2/Lambda/跨账号 |
| **AssumeRole** | 扮演一个 Role 获取临时权限 | STS |
| **SCP** | 账号/OU 权限上限 | Organizations |
| **Permission Boundary** | 单个 User/Role 的权限上限 | 防止自我提权 |
| **KMS key** | 加密密钥 | SSE-KMS、EBS/RDS 加密 |
| **Envelope Encryption** | 用数据密钥加密大数据,KMS 保护数据密钥 | KMS |
| **PII** | 个人敏感信息 | Macie |
| **CVE** | 已知漏洞编号 | Inspector |

## 八、运维与成本词

| 术语 | 白话解释 | 常见服务 |
|------|----------|----------|
| **Metric** | 数字指标 | CloudWatch |
| **Log** | 文本日志 | CloudWatch Logs |
| **Trace** | 一次请求经过哪些服务 | X-Ray |
| **Audit trail** | 审计记录 | CloudTrail |
| **Compliance rule** | 合规规则 | Config |

## 九、最容易混的词

| 易混词 | 一句话区分 |
|--------|------------|
| **Availability vs Durability** | Availability 是服务能不能访问;Durability 是数据会不会丢 |
| **Multi-AZ vs Read Replica** | Multi-AZ 管故障切换;Read Replica 管读性能 |
| **CloudWatch vs CloudTrail** | CloudWatch 看运行状态;CloudTrail 看谁调用了 API |
| **SQS vs SNS** | SQS 是排队给一个消费者;SNS 是广播给多个订阅者 |
| **Kinesis vs SQS** | Kinesis 可重放且多消费者读同一份流;SQS 消费后删除 |
| **WAF vs Shield** | WAF 防应用层规则攻击;Shield 防 DDoS |
| **Gateway Endpoint vs Interface Endpoint** | Gateway 只给 S3/DynamoDB 且无小时费;Interface 给大多数服务且收费 |
| **NAT Gateway vs Internet Gateway** | NAT 给私有子网主动出网;IGW 是 VPC 公网出入口 |
| **DataSync vs Storage Gateway** | DataSync 偏迁移/同步;Storage Gateway 偏长期混合访问 |
