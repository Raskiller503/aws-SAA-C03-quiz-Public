# 12 · 考前冲刺与答题套路

> 最后 1 周的"心法 + 套路"集合,把考场上的速度提一倍。

## 一、考前 1 周的复习节奏

### Day -7 ~ -5:错题二刷
- 用本仓库 quiz-app 的"错题"过滤器
- **不**做新题,**只过**之前错过的
- 目标:错题正确率 > 90%

### Day -4 ~ -2:模考 × 3 套
- 用 quiz-app 的"模拟考试"功能(65 题 / 130 分钟)
- 每套之间隔 1 天
- 错题立刻归因到学习框架某一章

### Day -1:**完全不学习**
- 复习一份**易混点速查表**(本章第六节)
- 准备好身份证 / 设备 / 网络

### 考试当天
- 提前 30 分钟到达 / 联网
- **不要**早交卷,有时间一定**回头检查**

## 二、考场答题节奏

```
130 分钟 / 65 题 ≈ 每题 2 分钟
```

### 三遍法

1. **第一遍**(80 分钟):快速过完所有题,**会的当场做,不会的 mark 一下跳过**
2. **第二遍**(35 分钟):专攻 marked 题,**仔细读、消除明显错误项**
3. **第三遍**(15 分钟):剩下还纠结的题,**用排除法蒙最有信心的那个**

⚠️ **重要**:**不要**在第一遍就死磕一题超过 3 分钟,你的时间预算就崩了。

## 三、答题套路五步法

```
1. 找"最 / 最少 / 唯一"等修饰词    ← 决定主导支柱
2. 扫一眼选项,看有无明显错误项     ← 排除掉
3. 找题目里的硬约束(性能 / 成本 / 时间) ← 缩小范围
4. 在剩下选项里找"运维最少 / 最 managed" ← 通常是答案
5. 实在不会,选你"听起来最像 AWS 推荐"的那个
```

## 四、典型陷阱关键词重读

(详见 [`00-从CLF到SAA的心智转换.md`](00-从CLF到SAA的心智转换.md))

| 陷阱关键词 | 通常排除 |
|------------|----------|
| **manual / 自己写脚本 / cron** | 运维高 |
| **EC2 自己装 X**(代替 RDS / EFS) | 运维高 |
| **NAT instance**(不是 NAT Gateway) | 单点 / 老旧 |
| **重写应用 / 大改架构** | 工作量大 |
| **Snowball** 用于小数据 | 大材小用 |
| **跨 Region 双向同步** | 复杂 |
| **EBS Snapshot 跨 AZ 然后恢复** 当主存储 | 中间步骤多 |

## 六、易混点速查表(考前 1 天看这个)

| 选项 A | 选项 B | 如何选? |
|--------|--------|---------|
| **SQS** | **Kinesis** | 队列消费完就删 / 流式有重放需求 |
| **SNS** | **EventBridge** | 简单广播 / 复杂事件规则 + SaaS |
| **ALB** | **NLB** | L7 路径 / L4 静态 IP UDP |
| **CloudFront** | **Global Accelerator** | 缓存静态 + HTTPS / 动态 + TCP UDP + 静态 IP |
| **Multi-AZ** | **Read Replica** | 可用性 / 读性能 |
| **EFS** | **EBS** | 多 AZ NFS / 单 AZ 块 |
| **DataSync** | **Storage Gateway** | 一次迁移 / 持续访问 |
| **DMS** | **DataSync** | 数据库 / 文件 |
| **Secrets Manager** | **Parameter Store** | 自动轮换 / 简单配置 |
| **Inspector** | **GuardDuty** | 漏洞 CVE / 威胁行为 |
| **CloudTrail** | **Config** | 谁做了什么 / 状态是否合规 |
| **WAF** | **Network Firewall** | L7 OWASP / L3-L7 通用 |
| **VPC Peering** | **Transit Gateway** | 点对点不传递 / 中心辐射 |
| **NAT Gateway** | **NAT Instance** | 99% 都选 Gateway |
| **Gateway Endpoint** | **Interface Endpoint** | S3/DynamoDB 免费 / 其他付费 |
| **Step Functions Standard** | **Express** | 1 年 / 5 分钟 + 高 QPS |
| **Aurora Global DB** | **Cross-Region Replica** | RPO ~1 秒 / RPO 分钟级 |
| **Spot** | **Savings Plans** | 容错任务 / 稳定承诺 |
| **Athena** | **Redshift** | 查 S3 / 数据仓库 |
| **Snowball** | **DataSync** | TB+ 离线 / TB- 网络好 |
| **CloudFormation** | **OpsWorks**(冷门) | 描述式 IaC / Chef/Puppet |
| **QLDB** | **DynamoDB** | 不可篡改账本 / 通用 NoSQL |

## 七、最后一句话

> SAA-C03 不是一门"知识考试",是一门"**判断力**考试"。  
> 它问的不是"AWS 提供什么",而是"你**会不会**选 AWS 提供的东西"。  
> 把每道错题都当作一次"判断力训练"。**坚持下去,你会在某一天突然发现 — 题目还没看完,答案就已经浮现了。**
